Nutrismart: AI Diet & Fitness Planner

A modern, responsive web application designed as a Final Year Project (FYP) to provide personalized diet and fitness plans powered by AI.
🌟 Key Features

    AI-Powered Planning: Uses Groq API to generate customized meal and workout paths.

    Smart Assessments: Calculates BMR & TDEE using the Harris-Benedict formula.

    Progress Analytics: Visual tracking of weight, BMI, and calorie expenditure using Recharts.

    Contact Integration: Fully functional contact form powered by EmailJS.

    PDF Export: Generate professional PDF reports for offline reference.

    Secure Architecture: Built with React, Tailwind CSS, and Firebase for authentication.

🛠 Technology Stack

    Frontend: React.js (Vite), Tailwind CSS

    Backend & Auth: Firebase

    AI Engine: Groq API (Language Model Integration)

    Data Visualization: Recharts

    Communication: EmailJS

🚀 Installation & Quick Start

1. Clone the repository

git clone <repository-url>
cd AI-Diet-Fitness-Planner

2. Install dependencies

npm install

3. Set up Environment Variables

Create a .env file in your root directory and add your API keys:

VITE_GROQ_API_KEY=your_groq_api_key_here
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key

4. Start development server

npm start
